# 多字形、复杂纹理与边缘输出

目标是用多种干净字形和可控退化训练逐像素笔画分割，并分别检查未见来源页及未见字符。单字训练、单种纹理或合成验证成绩，都不足以证明对所有汉字有效。

## 成对合成数据

每个样本从 `train` 中选择一张干净图及其掩膜，先对两者施加相同仿射/弹性形变，再只对输入图施加退化。目标始终表示干净字形：裂缝可能遮挡目标笔画，明亮碎斑可能与笔画粘连，但二者不会被写成新的前景标签。

`complex` 模式使用多尺度随机场产生不规则亮斑、局部明暗变化，加入方向性条纹、边缘污损、暗裂缝、腐蚀小点、模糊和 gamma 变化。复杂模式使用双线性标签重采样，保留边缘覆盖度，避免所有训练标签都带最近邻缩放的硬阶梯。网络训练使用 0–1 的软目标，二值评估按 0.5 切分。

独立导出可复用的图片/标签对：

```sh
.venv/bin/python -m hanzi_mask.synthesize output/multiglyph/manifest.json \
  -o output/multiglyph/new-pairs --count 1000 --size 256 --seed 123
```

`images/` 为含纹理输入，`masks/` 为 0/255 标签，`soft-masks/` 为包含边缘覆盖度的灰度标签。文件同名、同尺寸；`dataset.json` 记录来源哈希、种子和配置。所有模板来自训练清单，测试图片不参与纹理、背景或标签生成。输出目录必须是新的，固定配置/种子可重复生成。

已有研究使用噪声纹理迁移或生成式退化扩充文档二值化数据，见 [Bhunia 等，ICIP 2019](https://arxiv.org/abs/1810.11120) 和 [Dey 等，ICVGIP 2022](https://arxiv.org/abs/2211.06581)。这里采用独立实现的程序化纹理合成，未复现论文中的对抗网络或变分生成器。生成样例仍须与真实拓片纹理进行视觉比较。

## 平滑与抗锯齿

```sh
.venv/bin/python -m hanzi_mask.supervised output/an-character/manifest.json \
  -o output/an-character/new-edge-export \
  --checkpoint output/an-character/run-1000/best.pt --edge-sigma 0.7 --device auto
```

原始 `train/`、`test/` 二值结果继续保留。启用 `--edge-sigma` 后，增加：

- `train-smooth/`、`test-smooth/`：对前景分数作轻度高斯平滑再阈值化，保持原尺寸和 0/255。
- `train-antialiased/`、`test-antialiased/`：将分数等值轮廓按四倍分辨率采样后，以面积平均恢复原尺寸；边缘含中间灰度，用于显示。

sigma 单位为原图像素，范围 0–3，默认 0（关闭）。平滑不使用开闭运算或面积删除，但依然可能改变细笔画和窄间隙，应与原始掩膜复核。低分辨率纯二值图放大仍会出现像素阶梯；抗锯齿文件改善显示，不是额外的真实边界信息，也不可冒充严格二值标签。

## 首轮多字实验：2026-10-01

从原“安”实验的 8 个训练来源页内继续选择干净字形，以避免新增训练源进入原先的测试页。按“来源页 + crop 编号”去掉缩放副本，最终有 46 张训练图、25 个字：上下中之人仁公君國大天子安山年德心文日月永王生道金。

原始 8 张“安”掩膜保持不变；另外 38 张用中值滤波、Otsu、小区域筛选生成候选，经助手检查原图/掩膜/叠加图，移除记录在清单中的边缘条带和孤立杂点。它们是实验标签，尚未由专家确认所有笔画边界，尤其残损处可能仍有误差。

测试 45 张：原“安”的 25 张，加上天、人、國、年、德、道、愛、義、武、水各 2 张。所有测试来源页与训练隔离；愛、義、武、水这 4 个字从未进入训练。清单的 `unseen_character` 标记与训练字符集合冲突时会报错。

训练命令：

```sh
.venv/bin/python -m hanzi_mask.supervised output/multiglyph/manifest.json \
  -o output/multiglyph/complex-1600 --steps 1600 --batch-size 6 --size 256 \
  --augmentation complex --edge-sigma 0.7 --device mps
```

共 9600 个在线增强输入，验证使用固定的 24 个合成样例，检查点按合成验证选取。另导出 1000 对数据用于检查/复用，并未把这 1000 对导出文件重新读入训练。模型、数据量、输入尺寸、增强及标签插值同时改变，因此与原“安”模型的对照不能单独证明某一项改动的贡献。真实复杂测试没有人工像素真值，本轮只提供视觉对照，不计算真实 Dice/IoU 或“全字准确率”。

最佳检查点为第 1500 步，合成验证 Dice 约 0.9793；训练循环约 215 秒，含结果导出约 247 秒。原“安”权重在相同的 45 张测试图上重新推理，未继续训练。代表样例的观察：`17-44ad` 的“安”减少了原模型误留的左侧大块纹理，`69-fe23` 的“水”减少了边缘干扰；`37-f499` 的“愛”仍有粗斑粘连，`67-bebd` 的“水”右侧仍混有纹理。这些结果支持继续扩大真实配对数据与字形覆盖，尚不能证明普遍提升。

91 张训练/测试导出均保持原尺寸，原始和平滑掩膜为 0/255，来源原图和标签哈希未改变。0.7 像素平滑所改变的像素占比中位数约 0.24%、最大约 0.94%；这是变动规模，不是分割准确率或边界正确性。检查数据见 `validation.json`。

生成物保存在 `output/multiglyph/`：`manifest.json`、`masks/`、`masks-review-*.png`、`synthetic-1000/` 和 `complex-1600/`。图片、权重和数据清单不纳入 Git。原有“安”模型保持可单独使用。

`comparison.png` 展示原图、原“安”模型、多字模型原始二值、多字模型抗锯齿四列；`unseen-comparison-1.png`、`unseen-comparison-2.png` 包含八张未见字符测试。`paired-examples.png` 展示两组复杂纹理/掩膜。原“安”模型的平滑与抗锯齿输出位于 `an-baseline/test-smooth/` 与 `an-baseline/test-antialiased/`，其中也包含本次新增的其他字测试。
