# 生成式修复掩膜训练实验

使用原始拓片作为编辑目标，逐张调用内置 imagegen，按[修复提示词](prompts/glyph-restoration.txt)生成黑底白字轮廓，再训练本地 U-Net。生成步骤需要图像服务；训练和后续批量推理在本地完成。

本轮使用原“安”实验的 8 张训练图和 25 张独立测试图。只将训练原图交给 imagegen；测试图不参与标签生成、增强或检查点选择。模型、增强方式和训练入口沿用现有实现，未修改默认处理算法。

## 标签制作与检查

每张训练图分别作为唯一编辑目标，附上用户提示词、原图尺寸及保持位置/比例的要求。没有使用通用字体。原始生成图保留在 `output/imagegen-an/generated/`，最终选择、每次完整提示词、来源路径和 SHA-256 记录在 `generation.json`。

生成服务返回的图片分辨率高于原图。准备流程将完整画布按 AREA 插值恢复到原图尺寸，再以灰度 `>=128` 生成 0/255 标签，保存到 `masks/`；没有配准、自动裁边或形态学运算。`restored/` 保存最终选中的 8 张高分辨率纯黑白图，其宽高采用原图的同一个整数倍以保持精确画幅比例；生成服务原始输出则单独保留。

逐图检查原图、旧标签、修复标签和双色叠加。`20-a59e` 第一版存在整体上移，增加原图笔画坐标约束后重新生成，并选择第二版。其余图片仍有局部粗细、收笔和留白变化。检查记录表示可供探索性训练，并不表示经过专家逐像素确认。与旧掩膜的重叠值用于检查明显偏移，不能当作修复准确率。

这些标签包含对缺损笔画的推断，属于**生成式修复伪标签**。模型学习目标也包含这些推断，存在把错误结构学进去的可能。单纯尺寸一致和边缘平滑不足以证明与原字一一对应，需保留原图和叠加复核记录。

## 训练与对照

两组均使用相同的 8 张原图、25 张测试图、U-Net width 16、seed 42、256 输入、batch 6、1600 步、complex 增强及 edge sigma 0.7。两组分别使用旧候选掩膜和生成式修复掩膜；网络从头训练。

```sh
.venv/bin/python -m hanzi_mask.supervised output/imagegen-an/manifest.json \
  -o output/imagegen-an/restored-1600 --steps 1600 --batch-size 6 --size 256 \
  --augmentation complex --edge-sigma 0.7 --device mps

.venv/bin/python -m hanzi_mask.supervised output/an-character/manifest.json \
  -o output/imagegen-an/old-labels-1600 --steps 1600 --batch-size 6 --size 256 \
  --augmentation complex --edge-sigma 0.7 --device mps
```

复跑时改用尚不存在的输出目录。每组在线生成 9600 个随机增强输入，每 100 步用固定 24 个合成样例检查并保存最佳权重。两组验证目标也随掩膜改变，不能通过合成 Dice 的高低直接判断哪组恢复真实字形更准确。

另导出 1000 对可复用的复杂纹理输入、二值标签及软边缘标签。在线训练不读取这批导出文件。

```sh
.venv/bin/python -m hanzi_mask.synthesize output/imagegen-an/manifest.json \
  -o output/imagegen-an/synthetic-1000 --count 1000 --size 256 --seed 123
```

## 本地资源

以下路径相对于 `output/imagegen-an/`，均为 Git 忽略的生成物：

| 路径 | 内容 |
| --- | --- |
| `generation.json` | 原始提示词、逐次调用、最终选择、哈希和视觉检查记录 |
| `manifest.json` | 8 张修复训练标签与原 25 张独立测试的清单 |
| `generated/` | 内置生成服务原始输出，含保留的前一版本 |
| `restored/` | 最终 8 张高分辨率纯黑白修复图 |
| `masks/` | 8 张与原图同尺寸的 0/255 训练标签 |
| `label-review-1.png`、`label-review-2.png` | 原图、旧标签、修复标签及差异叠加 |
| `restored-1600/best.pt` | 生成式标签训练后的模型 |
| `old-labels-1600/best.pt` | 相同训练配置下的旧标签对照模型 |
| `restored-1600/test/` | 25 张真实测试图的原始二值预测 |
| `restored-1600/test-smooth/` | 原尺寸平滑二值输出 |
| `restored-1600/test-antialiased/` | 允许边缘灰度过渡的展示输出 |
| `synthetic-1000/` | 1000 对输入/掩膜以及软边缘掩膜 |
| `complex-comparison.png` | 四张复杂测试：原图、旧标签训练、修复标签训练和抗锯齿输出 |
| `test-review-1.png` 至 `test-review-5.png` | 全部 25 张独立测试对照 |
| `validation.json` | 两组训练配置、来源哈希、输出尺寸及二值性检查 |

恢复模型只训练了“安”的 8 种写法，不能据此声称覆盖其他字。真实测试没有人工像素真值，结果应通过逐图对照评估，不能将合成验证分数写成真实准确率。

## 本轮观察：2026-10-01

生成标签组选择第 1600 步检查点，合成验证 Dice 为 0.9792；训练及导出共约 232 秒。直接输入 8 张原训练图时，对生成标签的拟合 Dice 在 0.784–0.937 之间，明细保存在 `original-training-fit.json`。这些仍是训练图及伪标签上的拟合值。合成退化中的高分并不表示模型能够完整复刻 imagegen 推断的轮廓。

查看全部 25 张真实测试输出后，`35-9588` 顶部仍有粘连，`69-fe23` 两张图仍有断笔或碎片，低分辨率细笔画也可能缺失。当前模型可用于候选去噪与轮廓平滑，但尚未达到逐字完整修复。原始二值输出与额外平滑/抗锯齿结果分开保存，不能把后处理的显示效果误认为模型恢复了更多真实笔画。

相同配置的旧标签对照选择第 1500 步，合成验证 Dice 为 0.9793，训练及导出约 227 秒。逐图比较两组原始二值输出，`4-c265` 的 crop 72、`86-ae54` 的 crop 110 等样例减少了部分轮廓毛刺；`94-b7d0` 的细弱回锋笔画在生成标签模型中缺失更多，说明改善并不一致。两组合成分数接近，也不能用它们证明真实精度提升。

完成两组共 66 个训练/测试条目的导出检查：原图与标签哈希不变，四类输出保持原图尺寸，原始和平滑掩膜均为 0/255；最终 8 张高分辨率修复图保持原画幅比例和纯黑白。1000 对合成数据的同尺寸/二值检查通过，已保存模型与最终标签的来源记录相符。本次仅新增实验文档与本地生成物，未修改运行源码，未重复运行源码测试套件。
